# MRTdle

A daily guessing game: find the mystery Singapore MRT station.

Type a station name (or code like `NS17`), pick it from the dropdown and press **Enter**. Each guess adds a row of hints:

| Column | Green | Orange | Red |
| --- | --- | --- | --- |
| **Line** (NS, EW, NE, CC, DT, TE) | same line(s) | shares at least one line | no shared line |
| **Structure** (underground / above ground / both) | same | overlaps (e.g. interchange vs. one side) | different |
| **Distance** (straight-line km, arrow points to the answer) | 0 km | within 5 km | further |
| **Stops away** (fewest stations, switching lines allowed) | 0 | within 5 stops | further |

The background map draws every station and lights up your guesses. Progress is saved in the browser per day, and a new station is picked every midnight Singapore time (every station appears once before any repeats). Hints are computed server-side so the answer isn't sent to the browser.

## Run

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/flask --app app run
```

Open http://127.0.0.1:5000.

## Tests

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/pytest
```

## Data

`data/` is generated by `python scripts/build_data.py` and committed so the app runs offline:

- `stations.json` – 146 operating MRT stations (LRT excluded) with codes, lines, structure, coordinates, plus the track graph.
- `distances.json` – precomputed km and bearing between every pair of stations.
- `stops.json` – precomputed fewest stops between every pair (BFS over the line graph; changing lines at an interchange is free).

Station names, codes and coordinates come from [cheeaun/sgraildata](https://github.com/cheeaun/sgraildata), which compiles Wikipedia, LTA and OpenStreetMap data (includes Circle Line Stage 6). Underground / above-ground status per line is defined in `scripts/build_data.py`, based on Wikipedia. Re-run the script when new stations open.
